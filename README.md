# ejemplo-basico-retype
Ejemplo basico de configuracion y publicacion de paginas de retype.

Seguimos los pasos de instalacion de: https://retype.com/guides/installation/
Elegimos instalar y usarlo mediante la CLI de dotnet.

Tambien vamos a hacer un deploy automatico a cloudflare pages con cada commit, este deploy lo hace cloudflare en: https://ejemplo-basico-retype.pages.dev/
